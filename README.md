## Objetivo

O objetivo deste trabalho é estudar mecanismos de comunicação entre processos e threads, utilizando:

- Sinais;
- Pipes;
- Threads;
- Memória compartilhada;
- Semáforos;
- Mecanismos de sincronização.

As implementações foram desenvolvidas em linguagem C utilizando recursos POSIX.
